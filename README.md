# Cadastro de Pessoas em Python 🚀

Sistema modularizado desenvolvido em Python para realizar o cadastro de novas pessoas e a consulta de dados armazenados. O projeto foi estruturado seguindo as melhores práticas de organização de código e tratamento de erros.

## 🛠️ Funcionalidades
* **Menu Interativo:** Interface limpa e amigável direto no terminal.
* **Validação de Dados:** Sistema inteligente que impede o cadastro de idades inválidas.
* **Persistência de Dados:** Os dados são salvos e lidos diretamente de um arquivo de texto (`.txt`), garantindo que as informações não sejam perdidas ao fechar o programa.
* **Modularização:** Organização profissional separando as funções do sistema das bibliotecas de interface e manipulação de arquivos.

## 📁 Estrutura do Projeto
* `sistema.py`: Arquivo principal que executa o fluxo do programa.
* `lib/`: Pacote contendo os módulos de interface (`interface`) e de manipulação de dados (`arquivo`).
* `arquivo.txt`: Banco de dados simples em formato de texto para armazenamento das informações.

## 🧠 Aprendizados Aplicados
* Tratamento de exceções em Python (`try/except`).
* Criação e manipulação de pacotes e módulos personalizados.
* Leitura e escrita de arquivos externos.
